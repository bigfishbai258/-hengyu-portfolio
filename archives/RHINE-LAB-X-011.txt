ZHANG HENGYU · DESIGN PORTFOLIO
FILE X-011 / 徐州城市图标
XUZHOU / ICON SYSTEM

设计工具：Photoshop / Illustrator / Seedream 2.0
项目信息：个人设计作品集
创作者：张恒瑀
项目类型：DESIGN PORTFOLIO

将徐州及周边地标、建筑与代表性美食转化为图标，提取对象的轮廓和色彩，形成具有地域特征的视觉集合。

研究记录
1. 信息组织：以“设计概念—色彩提取—图标展示”组织信息，呈现从文化对象到图形语言的联系。
2. 表现重点：不同建筑保留各自的轮廓特征，以相近的体积感和底座结构建立系列关系。
3. 从轮廓到适配：从建筑照片中提取主体轮廓，再转化为简化的图形与色彩表达；页面展示了照片、剪影与彩色图标的演变。
4. 识别检查：以黑白效果对照图形轮廓，查看识别是否依赖色彩。
5. 尺寸检查：并列呈现 50%、100%、150% 的大小变化，展示不同尺寸下的视觉效果。
