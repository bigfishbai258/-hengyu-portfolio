# 张恒瑀 · 个人设计档案

直接运行「打开网站.cmd」，或在本目录执行 `node serve.mjs`。已包含构建好的 dist，无需重新安装即可在已安装 Node.js 的 Windows 电脑打开。

基于 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI) 原项目改编，保留原三维模型、开场时间轴、档案阵列、抽取动画、360°查看、主题和动效设置。原项目 MIT 许可见 LICENSE。作品版权属于张恒瑀。

21 份设计档案，包含毕设系列总览及 5 张海报、其余作品集项目与个人信息。毕业设计主题《AIGC辅助设计增效主题海报研究》，负责人张恒瑀，面向设计行业从事人员。

方向键切换分类与档案，Enter 读取，Esc 返回，/ 搜索。点击「全屏查看作品」浏览图片，左右切图；「设计说明」保留项目叙述；「作品图集」查看整组；视频项目提供观看链接；完整原 PDF 可在项目中打开。

源码：src；文字与图片索引：content/archives.json；作品：public/works；原作品集：public/portfolio.pdf。修改后执行 `npm install` 与 `npm run build`；开发预览执行 `npm run dev`。

离线缓存包含作品、字体和模型。外部视频需联网。在线站点沿用当前私人访问权限。
