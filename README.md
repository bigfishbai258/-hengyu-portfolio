# 张恒瑀 · 个人设计档案

双击 **打开网站.cmd**，浏览器会打开本地网站。关闭运行窗口会停止本地服务。已附构建好的 `dist/`，启动不需要重新安装依赖。

## 内容

- 15 个项目：毕业设计、海报与视觉、图形与信息、品牌与三维、动态与影像。
- 毕设主题《AIGC辅助设计增效主题海报研究》；负责人张恒瑀；目标用户为设计行业从事人员；宣传先进工具对设计行业的增效，鼓励学习并掌握先进工具。
- 毕设保留 PDF 内三张界面视觉海报和新增的《改得快》《理得清》两张海报。显示标题按实际画面标注。
- 完整作品图、设计说明、个人能力、教育信息、邮箱，以及原 PDF 下载。
- 三项视频使用 PDF 原有的外部观看链接和二维码；未将二维码当成视频画面，也没有虚构视频预览。

## 使用

- 首页立体档案可点击打开项目，也可滚动到作品索引浏览所有项目。
- 分类与检索可以组合使用；按 `/` 聚焦检索。
- 详情中的图片可放大；左右键切换图片，Esc 关闭大图或项目。
- 暂停动态会保留至下次访问；支持系统减少动态偏好。
- 手机可浏览完整作品、详情、视频入口和联系方式。

## 编辑与构建

本地运行需要 Node.js 22.12 或以上版本。编辑源码前执行 `npm ci`，开发使用 `npm run dev`，构建使用 `npm run build`。

项目内容在 `src/projects.js`；原 PDF 提取记录在 `src/source-pages.json`；图片与原 PDF 在 `public/`。源文件修改后，重新构建才会更新双击入口打开的版本。

部署时上传 `dist/` 的完整内容至静态网站托管服务。所有作品、字体和运行库均随构建输出提供，页面渲染不依赖外部字体 CDN。
